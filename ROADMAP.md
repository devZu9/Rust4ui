# ROADMAP — Rust4ui

Текущая версия — только насущные задачи (`[ ]`). Выполненные пункты уходят в `logs_archive/roadmap/` (файл версии). Идеи и отложенное — в `ROADMAP-IDEAS.md`.

> JSON → UI → Rust. Быстрое прототипирование интерфейсов на egui.

### v0.5.1 — Оставшиеся виджеты и полировка (продолжение v0.5) *(текущая)*

- [ ] Отключение сторон бордюра — возможность отключить любую сторону (top/right/bottom/left) у виджетов с border, чтобы делать уголки или односторонние полоски

- [ ] MenuBar
  - [ ] Кастомизация показа иконок в MenuItem — настройка видимости иконок (всегда/при наведении/скрыть)
  - [ ] Состояние _focus на раскрытом меню можно настраивать через постфикс
  - [ ] Настройка авто-раскрытия после клика (т.е. первый клик раскрывает пункт меню, а дальше мы просто водим и меню раскрывается из-за hover)
  - [ ] Shadow на MenuBar — протестировать и донастроить shadow на MenuBar и его children
  - [ ] MenuItem: width — явная ширина пункта меню. При `stretch: true`: если ширина больше widest — попап расширяется, все кнопки подтягиваются. При `stretch: false`: только эта кнопка шире, остальные не меняются. Меньше контента быть не может — padding не даёт
  - [ ] MenuItem: icon_gap — раздельный рендер иконки и текста с настраиваемым отступом (сейчас склеены в одну строку)
  - [ ] `align_children` не работает — align не наследуется через `_children`. Нужно добавить поддержку `align_children` для MenuItem и других виджетов
