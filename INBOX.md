# INBOX — почта между сессиями

Очередь сообщений от агентов других сессий (других проектов) к агенту **этой папки**. Агент этой папки разбирает почту при старте сессии (`/new-session`, шаг «INBOX») — без чтения всех журналов.

**Монополия:** INBOX — почта ТОЛЬКО для агента папки, в которой лежит (корень текущей сессии, `git rev-parse --show-toplevel`). Агент чужой сессии, правящий эту папку как внешнюю директорию, может ТОЛЬКО дописать свою запись (сверху) — старые записи не читать, не удалять.

## Формат записи (новая — СВЕРХУ, по этому образцу)

```markdown
## 2026-08-05 01:30 — [обновление]

- **От:** сессия Rust4ui
- **Тема:** logs-md-files — контроль после записи в журнал
- **Суть:** добавлен блок «Контроль после записи» (пункты 1–5)…
- **Коммит:** нужен
```

## Типы записей

| Тип | Что передаёт отправитель | Реакция агента-получателя |
|-----|--------------------------|---------------------------|
| `[обновление]` | Изменились файлы: что, где, почему | Проверить файл → сверить с описанием → проверить версию → принять контекст → сверка с SESSIONS → коммит (по команде) |
| `[инструкция]` | Шаги, которые нужно сделать | Выполнить, если действие недеструктивное и в рамках прав; иначе — показать и спросить |
| `[опыт]` | Пробовали A, B, C → результат X, но пользователь хотел Y | Проанализировать → предложить варианты → ждать подтверждения пользователя |
| `[вопрос]` | (зарезервировано, не используется) | — |

## Цикл обработки (агент-получатель, своя папка)

1. Прочитай запись → определи тип.
2. Реагируй по таблице выше.
3. Сверка с SESSIONS.md: запись об этом уже есть → ничего; нет → перенеси.
4. Удали запись из INBOX — ТОЛЬКО после завершения реакции.
5. Коммит — по команде пользователя.

## Правила для отправителя (чужой INBOX)

- Правишь файлы вне текущего проекта (внешняя директория) → после правки допиши запись в INBOX.md той папки (создай файл по этому образцу, если его нет).
- Формат записи знаешь отсюда / из скилла `skill-github` — при дописывании чужой INBOX не разбирай: только вставка своей записи сверху.
- Старые записи чужого INBOX не читать и не удалять.
